学生：老师好，上面是逐句精读部分的视频。目前美术层暂时用分镜代替，完整视频我还在制作中，主要想请教：目前的教学层UI设计存在哪些问题，后续优化的方向应该怎么走？


老师回复：

第七部分的教学UI，不再承担“让学生重新做一次判断”的任务，而是承担“把学生和AI已有的判断带回诗句，用文本证据验证，并让前三句的可分类性与第四句的不可分类性发生视觉冲突”的任务。

具体建议：

一、右侧大卡片应该减，但不是简单“越到后面越小”

现在四句都采用：

大标题卡 + 解释文字 + 标签 + 坐标

容易形成四张规格基本一致的“PPT知识卡”。

而第七部分的讲稿实际上不是四段平行解释。

它有非常明显的递进：

第一句——下沉
第二句——继续加重，沉到底部
第三句——突然离开巴山，跃向西窗
第四句——两个时空同时出现，无法单点定位。

所以卡片也不能四句等权。

第一、二句

可以保留右侧解释区。

因为这一阶段还在帮助学生建立“情感地图怎么读”。

但不要做成很大的封闭黑色矩形。

更适合：

诗句较大 + 一句极短证据 + 淡底/无完整边框。

例如：

君问归期未有期
归期未定，现实仍停在巴山。

第二句：

巴山夜雨涨秋池
现实没有离开，情绪却继续下沉。

这样就够了。

第三句

到了：

何当共剪西窗烛

解释框明显退出主视觉。

因为这一句最值得看的不是文字解释，而是：

青色巴山 → 金色西窗

以及点在地图上的跨越和跃升。

右侧只需要：

何当共剪西窗烛
从现实滑向想象。

然后让动画完成其余解释。

第四句

这里我建议：

最关键的2—3秒撤掉右侧解释卡。

因为讲稿本身已经非常适合被画出来：

人在想象的将来，话题却回到此刻的巴山。
场景是温暖的，内容却是孤独的。

因此画面应该先让评委“看见”：

西窗仍在。
巴山重新出现。
两个位置同时成立。

这几秒只保留：

美术层 + 情感地图 + 金点 + 青点 + 极细联系线。

最后再补一句短文字：

一个现在，被带进了将来。

这比放一整块解释文字高级得多。

二、“回看 → 证据 → 落点”

现在结合完整讲稿来看，由于学生判断已经发生在第六部分：

“先凭第一感觉作一次判断……接下来，把同样的问题交给AI。”

第七部分应该是：

回看你的判断 → 找诗句证据 → 点自然落下

例如第一句开始：

画面只短暂出现一个很轻的提示：

你的落点呢？

不需要真的等待作答。

然后旁白：

“这是现实中的问答。对方问归期，诗人只能回答‘未有期’。”

随着“现实中的问答”，青色点进入巴山一侧。

随着：

“情绪从一开始就不是平稳的，而是向下沉。”

点向下移动。

于是学生看到的是：

不是老师宣布答案，而是答案被诗句里的证据推出来。

这比“重新提问一次”更符合现在的课程结构。

三、精确数字应该从第七部分教学UI中退出

你现有UI里的：

−2
−4
+3

在AI环节有合理性。

因为Prompt明确要求AI：

“用−5到+5表示情感倾向。”

所以AI界面里出现数字完全可以。

甚至很有价值。

因为它代表的是：

AI试图把情感标准化、量化、分类。

但是第七部分已经进入文学精读。

讲稿自己使用的语言是：

“偏下方”
“沉到最低点”
“情感跃升”
“这个点，标不准”。

而且附录已经明确注明具体坐标数值：

“答辩深入追问时使用，不放入学生微课正文。”

所以建议形成一个非常漂亮的视觉区别：

AI层：

−2 / −4 / +3 / 明确分类

人的精读层：

下沉 / 更深 / 跃升 / 重影

这实际上会强化AI教学逻辑：

AI善于给坐标，人开始追问坐标装不下什么。

第四句“标不准”才真正有力量。

四、横轴保留现在的“复合时空”，但去掉数学刻度感

因为讲稿对横轴的定义并不是单纯时间：

左侧：想象中的将来——西窗归处
右侧：正在经历的现实——巴山夜雨
横轴代表诗人的心理移动——从巴山出发，滑向想象中的归处；又从归处回望巴山。

所以最适合的版本仍然是：

归处西窗 · 将来 ←————→ 巴山 · 此刻

纵轴：

温暖 / 期待 ↑
孤寂 / 沉郁 ↓

不要0、±1、±2、±5。

这样学生看的是：

方向关系

而不是：

数学测量。

这和讲稿里“我们先不把它当成严格的数学坐标，而把它看作一张情感地图”完全一致。

五、三套重复文字考虑减

现在同一句往往同时存在于：

坐标点旁边、顶部标签、右侧标题、解释正文。

这会让教学UI显得“信息很多”，但实际信息重复。

建议以后明确分工：

坐标区只回答：

在哪里？

例如：

① 巴山·此刻

不要再写完整诗句。

右侧诗句区只回答：

正在读哪一句？

例如：

君问归期未有期

极短解释只回答：

为什么这样落？

例如：

归期未定，仍在现实。

这样一来：

位置 / 文本 / 证据

成为三个不同层级。

而不是三个地方重复解释同一个结论。

六、四个点仍然应该逐个生成，考虑“让方法被建构出来”

现在一开始就把①②③④以幽灵状态全部摆在地图上，我觉得不好。

因为讲稿第六部分的方法明确规定：

第一步判断位置；
第二步判断情感；
第三步把每一句安放在地图上；
第四步将这些点依次连接，找到折叠点。

关键词其实是：

依次。

所以UI最好真正执行这个“依次”。

第一句出现①。

第二句时①留下轨迹，②生成。

第三句时①②变成已经形成的阅读路径，③生成。

到了第四句——规则突然不能继续。

前三句都是：

一句 → 一个位置

第四句却变成：

一句 → 两个位置同时成立

这才是最重要的视觉认知冲突。

所以第四句不是“④突然出现一个更漂亮的特殊点”。

而应该是：

④根本一开始无法生成成一个普通点。

这一点非常重要。

七、第四句应该成为整个教学UI第一次真正“失灵”

这是我建议强化的地方。

前三句中，情感地图很顺利：

① 落点成功。
② 落点成功。
③ 落点成功。

观众已经建立预期：

每句诗都能被这个工具装进去。

到了：

却话巴山夜雨时

突然出问题。

推荐动画顺序

“却话……”

西窗金点继续存在。

旁白：

“人在想象的将来——”

金点轻亮。

读到：

“巴山夜雨……”

原本已经退到背景中的巴山青点重新亮起。

旁白：

“话题却回到此刻的巴山。”

此时画面第一次出现：

🟡 西窗·将来 + 🔵 巴山·此刻

同时成立。

不要急着出现◎。

先停极短的一拍。

让观众感知：

一个点放不下。

然后旁白：

“场景是温暖的，内容却是孤独的。”

两个点之间出现极细的牵引线。

再到：

“现实的夜雨，被诗人带进了将来的灯光里。”

青色巴山意象开始进入西窗暖光，美术层与地图层同步。

最后：

“这个点，标不准。”

两个点的视觉关系压缩成：

◎

这时才出现：

时空折叠点

这样“◎”不再只是设计出来的符号。

而是学生亲眼看见：

因为普通点失效，所以不得不发明◎。

这是两种完全不同的教学效果。

八、第四句“却话巴山夜雨时”大约50秒以后的画面上方，橙色小标签写的是：“双重坐标共振”

建议从第一层UI退出

由于讲稿本身其实用了一套更好的语言：

“人在想象的将来，话题却回到此刻的巴山。”
“场景是温暖的，内容却是孤独的。”
“现实的夜雨，被诗人带进了将来的灯光里。”

这些语言既准确，又有诗性。

所以学生第一次面对第四句时，不需要：

双重坐标共振（一个诗句，同时牵涉两个坐标位置。）

这样的术语。

建议分层：

学生层：

一个现在，被带进了将来。
两个时空，同时在这里。

教师总结层：

时空重影点 ◎

答辩层：
再谈双重坐标、复合变换等理论。

这与整份讲稿本身设计的“学生层—评委层—答辩层”分层原则是一致的。

九、“赛博”建议弱化，但不能弱化掉AI感


课是AI+微课教学比赛，现代技术感是合理的。

问题只是：

现在某些时刻UI的发光边框、矩形面板、节点、标签同时存在，容易让人先看到“界面”，后看到“诗”。

所以方向应该是：

保留技术秩序，降低技术噪声。

具体来说，边框可以更细，外发光减弱，完整矩形减少，黑色面板更加透明，坐标网格再淡一些；青色与金色节点保留，因为它们已经承担“巴山现实 / 西窗想象”的认知编码。

尤其到了第四句：

HUD应该主动退场，美术层应该主动上场。

因为前面是“分析诗”，第四句开始真正进入：

感受诗。

最终效果不是：

水墨动画上盖了一套未来UI。

而应该是：

一套很轻的“诗性分析仪器”，把本来看不见的时空关系显影出来。

十、整段逐句精读最好重新定义为四种不同的视觉动作

这是目前最重要的总设计。

诗句	教学任务	UI动作	美术层动作	最终给学生留下什么
① 君问归期未有期	确认现实	落点 + 下沉	巴山独处、冷色	现实，此刻，孤独开始
② 巴山夜雨涨秋池	情绪加重	同侧继续下沉	雨、水、秋池加深	时空没变，情感更沉
③ 何当共剪西窗烛	第一次跨越	横移 + 跃升	冷青 → 暖金，西窗出现	从现实滑向想象
④ 却话巴山夜雨时	原规则失效	双点 → 重影 → ◎	西窗中重新浮现巴山夜雨	两个时空被压进一句诗

这样，四句不再是：

卡片1 → 卡片2 → 卡片3 → 卡片4

而是：

下沉 → 深沉 → 跃升 → 折叠

这实际上已经和讲稿结尾总结完全咬合：从巴山现实坠落，到归处西窗的想象跃起，再到折叠点停住。

十一、第三句到第四句应该成为整段真正的高潮

这两句之间不要只是“下一张卡”。

建议把视觉节奏设计为：

第三句：移动

青点离开巴山区域。

→

西窗建立

金色暖光成为新主场景。

→

第四句开始

西窗不消失。

→

巴山重新浮现

不是切回巴山，而是巴山作为“被谈论、被记忆的此刻”进入西窗。

→

两个位置同时成立

地图第一次失效。

→

重影

→

◎

→

折叠

这也与讲稿最关键的一句完全对应：

“巴山没有消失，它变成了将来重逢时可以讲述的记忆。”

所以这里千万不要做成：

西窗镜头 → 切巴山镜头。

必须是：

西窗仍在，巴山回来。

这不仅是美术问题，也是你“折叠”和“跳跃”的根本区别。
